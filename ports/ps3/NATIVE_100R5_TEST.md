# 1.0.0-r5 软解短缓冲与控制栏修复

r4 实机已确认竖屏 720p 软件解码出画面。日志显示下载队列通常还有约 4 秒，但画面仍领先声音 34–39ms 时便进入缓冲，几十秒内触发 24 次；每次又强制显示全屏控制栏。

- 控制栏不再被短缓冲立即弹出。连续缓冲达到 750ms 才自动显示，恢复后至少保持约 1.5 秒，避免立即闪退再闪现；手动控制栏和暂停仍可使用。
- 软解音频起播前预备六帧已解码画面，完成很短视频的解码时允许提前起播。
- 允许约 80ms 的短暂画面落后，减少提前暂停。恢复条件增加六帧兜底，避免高帧率视频因十帧缓冲池无法凑够固定毫秒数而卡住。
- 软解线程优先级由1100调到900，提高解码获得CPU时间的机会；仍低于音频输出优先级。
- 没有降低分辨率、关闭去块滤波或主动丢弃非参考帧。PPU软解性能并不代表Cell所有SPE已用满。

实测：重播上一条竖屏720p，保持控制栏隐藏观察30秒；主动呼出/隐藏控制栏各一次，再测试暂停和跳转。检查短缓冲次数、音画差及状态栏闪烁是否改善。保留BIBI_PLAY.LOG。

r5 调度调整的实际效果仍需 PS3 验证。源码保存在本仓库，安装包可按构建说明生成；没有创建 GitHub Release。
