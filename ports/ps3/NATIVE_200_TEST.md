# bibilabu PS3 2.0.0 — 详情页、会话缓存、中文输入与弹幕

## 本版行为

- 清晰度菜单最高 720p。选流过滤和 playurl 请求也限制到 64 档，1080p 不显示、不请求；原有 720p 的分离下载、YUV/RSX 输出与联合缓冲继续使用。
- 每个栏目首次成功加载后保留本次运行的内容；切换栏目不刷新，恢复已浏览的分页、收藏夹和搜索结果。正在加载时离开，完成结果仍写入缓存。手动三角刷新会使当前栏目的缓存失效并重取第一页；重启进程清空缓存。切换登录身份清理缓存，避免混用账号数据。网络线程重启保留同账号缓存。
- 会话缓存最多保存 256 个页面，不做超时更新或自动淘汰重取。到容量上限时提示重启。缩略图另有最多 8 MiB/512 项的压缩内容缓存，解码像素仍按有限槽位复用；超过图片缓存容量的内容可能需要重新下载。
- 弹幕密度 0 关闭；1、2、3、4 最多分别显示 2、4、6、8 条。支持普通滚动、顶部与底部固定弹幕，使用视频音频时钟，暂停/缓冲时停止移动，跳转时重定位。高级、逆向、代码和 BAS 弹幕暂不支持。
- 弹幕按六分钟分段获取，响应最多 1 MiB，保留两个分段和每段最多 720 条抽样记录；网络缓冲充足时才下载。文字只在入场时光栅化到 2 MiB 图集，位置由原生 RSX 更新，不逐帧重绘全屏文字。API 不可用时播放继续，日志记录原因。
- 系统 OSK 显式启用简体中文、繁体中文和英文。搜索最长 80 个 UTF-16 单元；评论编辑最长 240 个，支持换行。若显式面板被固件拒绝，回到仍注册中文语言的系统面板，不再静默降为纯字母面板。
- 打开视频后进入详情页：左上视频，左下 UP 主、关注、点赞、评论区切换与写评论，右侧相关推荐或评论。UP 主主页显示资料及最多八条近期投稿。评论支持分页、全文查看、发表评论和回复所选顶层评论。
- 关注/取消关注、点赞/取消点赞以及发表评论，都需要在确认框中明确确认；评论先通过系统键盘编辑，再显示草稿确认。请求带登录 cookie 与 CSRF 字段，不记录 cookie、CSRF 或评论草稿。网络中断或接口失败不自动重发写入请求。

## 手柄操作

| 页面 | 操作 |
|---|---|
| 栏目列表 | 左右切栏目，上下选项目，三角手动刷新，R2 下一页 |
| 视频详情 | 方向键移动焦点，叉键操作，视频区域叉键/SELECT 全屏，三角暂停/继续，L1/R1 ±10 秒，圆圈回列表 |
| 弹幕 | 详情页或全屏按方块，在 0→1→2→3→4→0 间切换 |
| 右侧评论 | “评论区”按钮切换，R2 下一页，L2 第一页/刷新，叉键查看全文 |
| 评论全文 | 叉键/方块打开回复输入，圆圈返回 |
| UP 主主页 | 方向键选投稿，叉键播放，三角刷新投稿，圆圈回详情；浏览期间视频自动暂停 |
| 全屏 | 叉键暂停，上下清晰度，三角控制栏，方块弹幕密度，圆圈/SELECT 回详情 |
| 确认框 | 默认取消；左右选择，再按叉键确认；圆圈取消 |
| 退出 | START 弹出退出确认；PS 系统退出继续沿用现有路径 |

## 验证状态和限制

主机检查包括 API、TLS/Range、音频、解封装、会话缓存命中/刷新/异步返回/账号切换、中文转换、弹幕 protobuf 边界与密度/暂停/跳转、详情与评论解析、WBI 投稿查询、以及只经显式调用才发起的模拟写操作。详情页、评论区、UP 主页和确认框预览由实际 C 合成器生成，内容为示例，视频窗口实际透明。

公开只读接口实测拿到了视频详情、八条相关推荐、评论和真实弹幕分段；真实分段解析出 42 条受限采样记录。本机读取 UP 投稿列表遇到 HTTP 412，资料页仍可读。客户端保留失败提示和手动重试入口，不自动绕过或反复请求该限制。

关注、点赞、发表评论仅使用模拟接口验证了参数和状态流程，没有通过本轮开发工具执行真实账号写操作。中文系统键盘、RSX 弹幕、详情小窗、账号写入，以及新的后台线程组合仍需 PS3 实机验收。

## 实机重点

1. 覆盖安装后首次访问推荐、历史、收藏，再来回切换：内容和分页应保留；三角刷新后才变化。退出重开再检查首次加载。
2. 搜索中输入中文；登录后用“写评论”打开中文编辑，先取消一次确认，检查不会发布。
3. 播放已知正常的 720p 视频，在详情/全屏切换，调弹幕密度 0～4，测试暂停、缓冲和快进后的弹幕位置。
4. 切换相关推荐/评论，查看全文、分页、打开 UP 主主页。只有在确实希望关注、点赞或发布内容时才确认相应操作。
5. 提供 `BIBI_PLAY.LOG` 与 `.previous`。重点：`DANMAKU_SEGMENT`、`DETAIL_API_CODE`、`OSK_*`、`VIDEO_CLOCK`、`PERF` 与 `EXIT_CLEANUP`。

本版只保存在电脑，不自动复制到 U 盘。1.9.2 包保留作为已经反馈 720p 正常的版本。
