# bibilabu PS3 1.6.0

启用 HEN 后覆盖安装，沿用 WILIPRB01，保留原账号配置。新日志身份为 `BIBILABU_PS3_NATIVE_160`。

## 本次改动

- **视频**：1.5.0 已能初始化并取到第一帧，但第二个输出画面的 `0x80610106` 状态让应用立即中止。参考 Movian PS3 后端的处理方式，本版对这个已知 picture 状态保留警告，不单凭它停止播放；仍检查尺寸、属性、时间戳关联和 `vdecGetPicture` 返回值，未知错误照常中止。同时向解码器提供 MP4 的实际 DTS。
- **搜索**：日志显示旧版系统键盘加载返回 `0x8002b504`，未进入网络请求。改用 PSL1GHT 示例的全键盘和居中布局设置，并记录各设置结果；系统默认面板失败时有一次字母面板尝试，两者都失败则打开应用内简易键盘。
- **收藏**：读取当前账号的真实收藏夹列表，叉键进入夹内视频，R2 下一页，圆圈返回收藏夹列表。已在电脑端用同一账号只读验证：5 个收藏夹、首个收藏夹返回 16 条资源且有后续页。未将账号凭证、收藏标题或媒体加入安装包。
- **界面**：选中缩略图从 112×63 放大到约 136×76；标题相应右移，避免挤在一起。分类滑动、列表移动与缩略图大小使用约 180 ms 的缓出过渡，连续按键从当前动画位置继续，不跳回起点。播放界面不运行这些浏览动画。

## 搜索操作

在搜索分类按叉键打开输入，已有结果时方块键改词。系统键盘使用正常输入方式。

如果出现简易键盘：方向键选字符，叉键输入，方块键删除，L1 切大小写，START 或三角提交，圆圈取消。
简易键盘支持英文、数字、空格和 BV 号，不能替代中文输入法。中文仍依赖系统键盘。

## 这一轮请检查

1. 再播放刚才失败的视频，分别观察画面是否持续、声音是否正常、有没有花屏。只出现“播放中”不等于播放通过。
2. 播放 2–5 分钟，暂停恢复、返回列表再换一段视频；最后用 PS 菜单退出。
3. 收藏页是否能看到 5 个收藏夹，进入后能否选视频、翻页、返回。
4. 搜索是否打开系统键盘；若退到简易键盘，输入 `PS3` 并提交，检查结果及播放。
5. 左右切分类、上下选视频，观察新的大小和动画；壁纸读取与 PS 菜单处理保留 1.5.0 已有的实机成功路径。

回传 `BIBI_PLAY.LOG` 和 `WILI_EARLY.LOG`，并说明视频实际画面/声音和键盘类型。日志中的 `VDEC_PICTURE_WARNING` 不等于崩溃；如果能持续取帧会继续播放，但画面质量仍须肉眼确认。

## 验证范围

同一失败视频前 72 个 AU 已通过主机取包和 FFmpeg 严格解码；原有启动/退出 ABI、导入表、720p、音频、API、图片和线程回归继续保留。新增收藏数据结构、动画中断连续性、分类环绕、翻页重置测试与实际 UI 动画预览。

主机检查不能证明 PS3 解码输出质量、键盘或动画帧率已通过。本版的实机结论仍待本轮反馈。
历史暂不回写播放进度，切换清晰度仍从头开始。
