# bibilabu PS3 2.1.0 — 透明 XMB 页面与固定视频评论滚动

## 外观

- 视频详情和 UP 主页直接透出与首页相同的 XMB 静态壁纸；没有找到系统壁纸时沿用应用的 XMB 波纹背景。
- 移除详情页、投稿列表、评论区的灰色填充卡片。使用白色文字、细线、选中箭头和半透明轮廓；全屏控制层、清晰度选择和确认框也去掉灰色面板填充。
- 壁纸由 RSX 在视频后方绘制，UI 本身使用透明图层。视频画面本身保持正常不透明，不会因页面透明而褪色。没有加入实时模糊或动态 VSH 主题读取。
- UP 主页的投稿改为右侧纵向列表，使用相同的选中箭头与下划线。进入 UP 主页时视频保持原位置和大小，暂停行为沿用 2.0。

## 评论位置与操作

- 详情页、评论浏览和 UP 主页的视频区域均固定为逻辑坐标 `(32,48,800,450)`；主动切换全屏时才改为全屏。
- 左下方是独立的滚动区域，包含标题、UP 主操作、统计与评论。评论不再替换右侧相关推荐。
- 在视频区域按下进入 UP 操作，再向下经过弹幕密度进入评论。也可以选择“评论区”直接滚到评论。
- 上下键/左摇杆移动评论焦点并滚动，约 180ms 缓动，可中途改变方向；只裁切和移动左下区域。左侧带滚动条，右侧推荐保持原位。
- 评论焦点下按叉键查看全文；全文中的叉键/方块仍可编辑回复。R2 下一页，L2 返回第一页/手动刷新；当前仍每页最多六条，不进行无限追加。
- 评论区域按右可进入相关推荐，左可返回 UP 操作。UP 主页改为上下选择投稿，左/圆圈返回详情。
- SELECT 全屏/详情、三角暂停、L1/R1 跳转、方块弹幕密度和 START 退出确认继续可用。

## 实现与检查

静态页面和左侧滚动内容分别缓存；滚动只复制已排版内容的可见行，不逐帧重新光栅化整页文字。新增约 3.52 MiB 的滚动内容缓存，壁纸改为 4 MiB 对齐的主存映射，退出时解除映射。

检查覆盖：固定视频与滚动区互不相交；空评论/六条评论的滚动边界；焦点跨区域导航；动画中断连续性；评论滚动前后视频、顶部导航、右侧区域逐像素一致；面板内部无灰色 alpha 填充；详情/UP/评论/确认框的实际 C 合成器预览。完整构建还运行既有媒体、缓存、网络和账号模拟检查，以构建结果为准。

主机预览使用示例视频和默认 XMB 背景，不是 PS3 实机截图。新增 GPU 壁纸绘制、控制器滚动和长时间播放需要实机验证。

## 建议复测

1. 覆盖安装后打开同一个 720p 视频，确认详情页和 UP 主页透出当前首页壁纸，没有灰底卡片。
2. 从“评论区”进入评论，连续上下滚动、快速换方向、查看全文，再返回；视频位置和右侧推荐应保持不动。
3. R2 下一页、L2 刷新，检查新评论仍在左侧；切换全屏、弹幕和 UP 主页后返回。
4. 检查暂停/继续、音画同步、系统菜单和退出。若异常，保留 `BIBI_PLAY.LOG`，其中新增 `WALLPAPER_RSX_MAP/UNMAP`。

安装包只保存在电脑，不自动写入 U 盘。2.0.0 包保留作对照。
