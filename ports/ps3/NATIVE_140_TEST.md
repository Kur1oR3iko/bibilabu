# bibilabu PS3 1.4.0 实机验证

本包针对 4.93 CEX + HEN，沿用 WILIPRB01 标题 ID。先启用 HEN，再覆盖安装新 PKG。
不需要重新配置测试 BV，也不读取 WILI_BILI.INI。播放对象来自列表里实际选中的视频。
账号配置文件不包含在安装包里。

## 这次改了什么

- 原生 XMB 风格界面：横向分类、纵向列表、右侧封面和详情、静态蓝色光带。
- 固定 1280×720 UI 画布，RSX 按电视输出分辨率缩放。静止列表不持续重画。
- 字体与背景在主内存绘制、缓存；不再由 CPU 读写显存来混合文字。
- 恢复每次绘制前的命令缓冲余量检查与安全回收，防止持续播放耗尽 RSX 命令区。
- 请求/二维码、封面、列表、媒体取包、音频输出、日志分别有明确线程归属。
- 主线程不再因媒体 Range 下载等待 15 秒；网络慢时音频可以缓冲，手柄循环仍继续。
- 视频帧缓冲直接映射给 RSX，去掉每帧额外的 ARGB 整帧复制。
- 清晰度选择真正允许 720p AVC，最高 720p30；屏幕标签使用实际选中流的清晰度。
- 修复停止时重复释放、解码器未关闭就释放内存、映射帧缓冲累积，以及网络关闭顺序。
- 日志后台写入，保留上一次日志，满 4 MiB 轮转。修复旧版本超过 1 MiB 后拒绝打开的问题。
- 收藏和搜索尚未实现完整接口/输入，明确显示未接入，不再用热门列表冒充收藏。

## 操作

| 场景 | 操作 |
|---|---|
| 首页 | 左右 / L1 R1 切分类，上下选视频，叉键播放，三角刷新 |
| 账号 | 叉键生成二维码；已登录时方块键退出登录 |
| 播放 | 叉键暂停/继续，三角显示/隐藏信息，上下选择清晰度，圆圈返回 |
| 正在连接视频 | 圆圈取消请求 |
| 退出 | START；首页圆圈先返回分类，再按退出；PS 系统菜单也可退出 |

切换清晰度目前会从头播放。无法获得 720p 的片源会选择权限内的较低清晰度，并显示实际结果。
不支持 HEVC、AV1、1080p、720p60；API 元数据缺失帧率时仍需实机观察。

## 一次完成的测试

1. 停留首页并快速切换推荐、热门、历史，确认页面可响应、封面不会反复闪烁。
2. 登录后选一段普通 720p 视频，确认播放条显示 720P。连续播放至少 5 分钟，最好让一段短视频自然结束。
3. 暂停/继续，显示/隐藏信息条，返回列表，再换视频；重复至少 5 次。留意是否越来越慢或无法退出。
4. 按 START 退出，接回 U 盘，把 BIBI_PLAY.LOG 和 WILI_EARLY.LOG 提供给开发者。

## 日志位置

- U 盘根目录：`BIBI_PLAY.LOG`、`WILI_EARLY.LOG`。
- 硬盘备用：`/dev_hdd0/tmp/BIBI_PLAY.LOG`。
- 应用目录备用：`/dev_hdd0/game/WILIPRB01/USRDIR/BIBI_PLAY.LOG`。
- 上一次运行记录：同目录的 `BIBI_PLAY.LOG.previous`。

U 盘应在启动应用之前插好。正常日志身份应为 `BIBILABU_PS3_NATIVE_140`。
运行日志约每秒刷盘，正常退出会排空队列；硬死机/断电仍可能丢失最后少量记录。
发生 GPU/解码器退出超时会保留相关内存并结束进程，不会继续播放或释放仍被使用的缓冲。

本版本已通过主机侧构建、ABI/导入表/启动退出校验、ASan/UBSan 回归、720p30 本地合成 AVC 流的解析及主机解码检查。
这些不等于 PS3 已通过验证。720p 的实际流畅度、SPU 调度和 RSX 映射路径仍待本轮实机结果。
