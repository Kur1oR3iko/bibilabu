# bibilabu PS3 1.5.0

目标机器：4.93 CEX + HEN。先启用 HEN，再安装本版，覆盖 WILIPRB01 即可。原账号配置不随 PKG 覆盖。

## 针对本次实机反馈的修复

1. **播放初始化失败**：1.4.0 日志中两个 720p 片源都声明 AVC Level 5.1；程序直接向 CellVdec 查询 51，得到 `0x80610101`（参数错误）。CellVdec 接受的等级到 4.2。现在先验证 progressive / 8-bit / 4:2:0、720p 尺寸、DPB、时序和 HRD 限制；符合边界的过高等级声明才规范化到 4.1，同时处理配置及流内 SPS。不会重新压缩视频，也不会盲目修改不兼容片源。
2. **PS 菜单卡住**：旧版进入系统菜单后完全停止画面提交。日志仍有 ALIVE，但 draws 停在 49，也没有 EXIT 事件。现在静止页面仍持续提交缓存画面，继续驱动系统菜单/键盘；只停止应用输入，不停止 GCM flip。菜单打开时自动暂停播放，关闭后仅恢复由菜单暂停的视频。
3. **历史**：改用账号历史游标接口，解析作者、已看进度/看完状态，并支持 R2 下一页。接口错误与登录失效会直接显示。本版读取账号已有历史，尚不把本机播放进度回写到 B 站。
4. **搜索**：叉键打开 PS3 系统键盘，支持中文与英文。结果页方块键修改关键词，R2 下一页。搜索前通过官方接口取得正常客户端标识，避免缺失 buvid 的请求。不会自动轮换标识或重复重试 412。
5. **界面**：固定焦点的横向大图标分类，当前分类下方纵向视频缩略图与文字，方向键长按重复与左摇杆导航，文字阴影和更少的面板，接近 XMB 的十字布局。

## 系统壁纸

- 自动只读查找当前 PS3 用户的 `/dev_hdd0/home/XXXXXXXX/theme/wallpaper.png`。使用系统当前用户名与 `localusername` 匹配；只有一个用户时可直接选择。多用户无法确认时不会猜另一个用户的壁纸。
- 每 5 秒检测文件时间/大小变化；SELECT 可强制重新加载。
- 自动读取失败时，可以用 IRISMAN 把原始壁纸复制到应用 `USRDIR/wallpaper.png`，或 U 盘根目录 `BIBI_WALLPAPER.PNG`，再按 SELECT。文件实际内容可以是 PNG/JPEG。
- 图片最大 8 MiB、4096×2160 范围内且不超过 1920×1080 总像素，居中裁切到 16:9，轻微压暗以保证文字可读性。
- 这是保存的静态壁纸同步，不是捕获或嵌入 VSH 动态主题。软件运行时若系统无法修改壁纸，退出到 XMB 更换后，下次启动会读到新图片。
- 播放时暂停壁纸和封面加载，给视频留出带宽与内存。

## 本轮一次测试

1. 首页按 PS 键打开系统菜单，再返回；随后从系统菜单退出应用。先验证这条修复。
2. 重开后播放上次失败的任意视频，确认日志出现 `AVC_PS3_LEVEL source=51 decoder=41`、`VDEC_QUERY rc=0`，再观察画面和声音。没有画面也可以圆圈返回。
3. 历史页检查记录、进度与 R2 翻页；搜索页输入中文，确认结果并播放。
4. 看壁纸是否与系统保存图片一致；SELECT 强制检查。若失败，日志会记录读取/解析阶段。
5. 播放至少 5 分钟、暂停恢复、换视频，最后用 PS 菜单退出。

需要回传：U 盘根目录 `BIBI_PLAY.LOG` 和 `WILI_EARLY.LOG`，并说明视频是否有画面/声音、PS 菜单能否退出。
备用日志在 `/dev_hdd0/tmp/BIBI_PLAY.LOG` 和应用 `USRDIR/BIBI_PLAY.LOG`；上次日志是 `.previous`。
日志身份应为 `BIBILABU_PS3_NATIVE_150`。

## 验证边界

本版通过主机侧编译、启动/退出 ABI、解码器导入、ASan/UBSan、中文转换、历史/搜索响应、壁纸解码边界，以及原始/过高 Level 声明 720p AVC 流的规范化与 FFmpeg 解码检查。电脑端搜索接口也已返回结果。

这不能证明 PS3 上的新 SPS 路径、PS 菜单、系统键盘、用户目录读取或 720p 性能已经通过。上述项都需要本轮实机反馈。
