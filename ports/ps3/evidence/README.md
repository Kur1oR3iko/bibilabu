# 验证状态摘要

当前公开源码为 bibilabu PS3 1.0.0 的 r5 测试修订。

- 主机：软件 AVC 七参考帧的 720×1280 / 720×1278 样本解码、输出像素独立对比、取消/释放、UI/加载动画、短缓冲提示和持久设置等检查已通过。
- 构建：PPU 交叉编译、导入表/回调 ABI、SELF/PKG 结构及安装包内容校验已通过。
- 实机：横屏 720p 播放正常；r4 竖屏 720p 软件解码已出画面，但有卡顿和频繁短缓冲。
- 尚待确认：r5 调度/控制栏修复的实际改善幅度、不同片源的持续稳定性。

主机或包结构校验不等同于 PS3 固件和性能验证。原始实机日志、用户观看记录、设备地址与本地交付清单保存在开发者本地，不发布到此目录。历史文档中的日志引用仅用于说明当时的调查过程。
