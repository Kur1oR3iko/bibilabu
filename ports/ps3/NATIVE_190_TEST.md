# bibilabu PS3 1.9.0 — YUV / neutral Aero / up to 1080p30

本版包含 1.8.0 的 YUV420P 与半透明 Aero 播放界面，并补齐本地账号保存、PS3 XMB 风格导航提示音和最高 1080p、最高 30fps 的选流路径。安装包仅在电脑上生成，不写入 U 盘。

## 画质限制

- 清晰度按当前视频返回的 AVC 表示动态显示；只有 API 返回对应 DASH AVC/AAC 流时才展示档位。
- 1080p 仅接受固定帧率 VUI 明确标出不超过 30fps 的 AVC 流，且 SPS/DPB、参考帧和码率处于 PS3 解码器约束内。缺少帧率证据、超过 30fps 或实测 SPS 不匹配时拒绝该流；不会把 1080p60 降格冒充 1080p30。
- 用户选择 1080p 后，客户端按清晰度 80 发出 playurl 请求。1.8 及更早代码曾将请求上限截到 64，这个问题已修正。
- 1080p YUV 帧池会按实际编码尺寸分配，1920×1088 十槽约 32 MiB；还需计入 VDEC 工作区、视频输入、音频、网络与界面内存。
- 1080p30 是软件策略上限，不代表这台 PS3 已证明可持续解码 1080p。高码率或固件无法处理的片源仍可能失败，建议先用低码率 1080p AVC 测试片源。

## 界面与本地状态

- Aero 控制层保持半透明、细亮边缘和高光；高光、文字与播放控制使用中性灰/白色，不再采用蓝色强调色。
- 登录 cookie、用户 ID 和 refresh token 写入 `/dev_hdd0/tmp/bibilabu_config.json`，同时保存到应用目录并保留备份。日志只记录保存状态，不输出凭据内容。
- 页面切换、上下移动选择项和翻页时播放应用混音的短促双音提示。声音由合成波形生成，模拟 PS3 XMB 的轻提示音，不读取或复制系统专有音频资源。

## 本轮实机验收

1. 覆盖安装后登录，完全退出并重新启动软件，确认无需再次扫码；随后在断网启动、重新联网的情况下检查账号仍在。
2. 翻页、切换栏目和上下移动，确认提示音出现且视频播放时音频没有明显欠载。
3. 对一段实际支持 1080p30 的低码率 AVC 视频打开清晰度菜单，确认出现“1080P 最高30帧”，选择后检查 `BILI_SESSION_PLAYURL`、`AVC_PS3_PREFLIGHT` 和 `YUV_OUTPUT_READY` 日志中的实际清晰度、尺寸、参考帧与内存池大小。
4. 对仅有 1080p60、缺少可验证 SPS 帧率或高于 PS3 DPB 限制的视频，确认 1080p 不可用或选择后被明确拒绝，并可选择其它实际可用档位。
5. 检查中性 Aero 面板透明度、视频透出、RSX fence、音画同步、±10 秒跳转、退出确认和正常退出。

实机重点日志包括 `BIBILABU_PS3_NATIVE_180`、`YUV_OUTPUT_READY`、`AVC_PS3_PREFLIGHT`、`UI_SOUND_READY` 和 `CONFIG_SAVED`。PKG 静态检查通过不代表 PS3 上的 1080p 性能或新 RSX 混合效果已经验证。
