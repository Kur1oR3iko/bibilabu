# 2.4.0 账号观看历史和进度同步

此前 PS3 仅读取历史，没有任何播放进度上报。此次参照 upstream video_detail_api.cpp 的 /x/v2/history/report，补上登录后的账号同步。

- 视频真正显示首帧后首次上报，每 15 秒推进中的播放再次上报；暂停/恢复、跳转、播放结束、离开视频补报。
- 使用播放音频时钟的实际位置，单位为秒；完成时上报视频总时长。没有开始播放和未登录时不上报。
- 独立低优先级线程，最多 8 个待发视频，同一视频只保留最新位置；失败退避重试，不能把 HTTP 成功误认为业务成功。
- 退出尝试排空队列，最多保留 2 秒同步窗口；断网/强制关机不能保证最后一次位置送达。重新连网的同进程保留未发队列。
- 切换账号/退出登录撤销旧队列；日志不包含 Cookie、CSRF 或请求表单。
- PS3 本地历史分类依旧是本次会话缓存，手动 △ 刷新后才重新读取云端历史。

## 手机实测
1. PS3 与手机登录同一个 B 站账号；播放任意视频至少 20–30 秒，然后暂停。
2. 在手机刷新观看历史，检查视频和进度。
3. 在 PS3 跳到另一位置再返回列表，在手机刷新检查更新。
4. 若未出现，提供 BIBI_PLAY.LOG：HISTORY_REPORT 的 result=accepted 表示官方接口 code=0；retry 表示未确认成功。

编译与模拟服务回归不能代替真实账号实测。开发测试不向真实账号写入观看记录。安装包只保存在电脑，不写 U 盘、不提交 Git。
